# Store data-use answers

- **Data collected:** None. restoreyt stores only local feature settings, whitelist values, and local feature state.
- **Data sold or transferred:** None. No telemetry, analytics, OAuth, remote configuration, or third-party service exists.
- **Purpose:** Restore creator-authored YouTube titles, descriptions, and thumbnails after automatic localization.
- **Permissions:** `storage` preserves local settings; YouTube host access runs guarded restoration on matching pages.
- **User control:** Disable features in popup/options or remove extension storage by uninstalling restoreyt.
