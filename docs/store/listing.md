# Store listing draft

## Short description

Restore original YouTube titles, descriptions, and thumbnails when localization changes what you see.

## Long description

restoreyt runs locally, uses no telemetry, and keeps a channel whitelist in local extension storage. It restores visible metadata through guarded runtime contracts and degrades safely when YouTube changes. Audio, chapters, channel branding, and other unsupported surfaces stay omitted until evidence supports them.

## Single purpose

Restore creator-authored YouTube presentation after automatic localization or dubbing.

## Data use

No sale or transfer of data. No authentication. No third-party analytics. See [PRIVACY_POLICY.md](../../PRIVACY_POLICY.md).
