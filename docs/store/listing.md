# Store listing draft

## Short description

Restore original YouTube titles, descriptions, thumbnails, and selected audio tracks when localization changes what you see.

## Long description

restoreyt runs locally, uses no telemetry, and keeps a channel whitelist in local extension storage. It restores visible metadata through guarded runtime contracts and degrades safely when YouTube changes. Chapters, channel artwork, and other unsupported surfaces are omitted until evidence supports them.

## Single purpose

Restore creator-authored YouTube presentation after automatic localization or dubbing.

## Data use

No sale or transfer of data. No authentication. No third-party analytics. See [PRIVACY_POLICY.md](../../PRIVACY_POLICY.md).
